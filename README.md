# Student Marks Prediction

A beginner machine-learning project that estimates marks from study hours using **Linear Regression**.

## Run in VS Code
1. Install Python and VS Code.
2. Open this folder in VS Code.
3. In the terminal run:
   ```bash
   pip install -r requirements.txt
   streamlit run app.py
   ```
4. Open the local URL shown by Streamlit.

## Files
- `app.py` – Streamlit interface and ML model
- `students.csv` – Small illustrative sample dataset
- `requirements.txt` – Python dependencies

## Concepts
- Features and target variables
- Train/test split
- Linear Regression
- MAE and R² evaluation

**Note:** This is an educational demonstration, not a reliable way to predict a real student's results. Many factors affect exam performance.
